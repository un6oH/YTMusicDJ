# YTMusicDJ
Web app that creates a YouTube music playlist from based on any playlist, sorted to flow from one style, genre, or vibe to the next naturally.

AI use: Created with the aid of GitHub Copilot

Other's work:
server/utils/ModelWrapper.js and server/utils/modelsAudioPreprocess.js from essentia.js-benchmarks (https://github.com/MTG/essentia.js-benchmarks)
Mood inference models from essentia.js. See included license.
